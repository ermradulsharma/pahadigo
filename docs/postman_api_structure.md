# 📑 PahadiGo: Postman API Folder Structure

This document provides a professional overview of the folder structure in the `PahadiGo.postman_collection.json`. These folders are designed for end-to-end API testing of the PahadiGo platform.

---

### 🛡️ Authentication
**Description**: Contains all authentication and session-related APIs for the application. These endpoints handle OTP-based login, social logins (Google, Facebook, Apple), user verification, token generation, session validation, and logout. All secured APIs across the system depend on the access tokens generated by these endpoints.
* **Key Endpoints**: `Send OTP`, `Verify OTP`, `Google Login`.

---

### 👤 Vendor
**Description**: Endpoints related to vendor management, including business registration, profile updates, and catalog management. These APIs allow vendors to manage their identity and the services they offer on the PahadiGo platform.

#### 📁 Business Details
**Description**: Handles the core identity and legal verification of the vendor business, including profile information and KYC documents required for onboarding.
* **Profile**: APIs to manage the vendor's professional profile, including contact details, business category, and address.
* **Documents**: Securely upload and manage KYC documents such as Aadhaar, PAN Card, and GST Registration files.

#### 🏦 Bank Details
**Description**: Manage vendor bank accounts and cancelled cheque documents for secure payment settlements and verified transactions.

---

### 📦 Packages
**Description**: The central folder for managing travel services (Packages). It covers the full lifecycle of adding, updating, and removing service items.

#### ✨ Package Items
**Description**: Specific endpoints to add and manage different types of travel items including Homestays, Hotels, Camping, Trekking, and more.
* **Categories**: `Homestay`, `Hotel`, `Camping`, `Trekking`, `Rafting`, `Bungee-Jumping`, `Paragliding`, `Skiing`, `Bike-Scooter-Rental`, `Chardham-Tour`, `Custom-Trip`.

---

### ⚙️ Environment Variables Consistency
The collection is perfectly synced with `PahadiGo.postman_environment.json`. All secured requests now use the correct **`{{auth_token}}`** variable for authentication.

**Local Testing Setup:**
1. Import `PahadiGo.postman_environment.json`.
2. Select the `PahadiGo` environment in Postman.
3. Use `Send OTP` and `Verify OTP` to populate the `auth_token`.
