# Vendor Business Profile Creation Request

This document outlines the form-data structure used in Postman for creating a vendor business profile. These fields are populated dynamically by the pre-request script.

## API Endpoint
`POST /api/vendor/business/profile/create`

## Request Body (Form-Data)

| Key | Value (Placeholder) | Description |
| :--- | :--- | :--- |
| `ownerName` | `{{ownerName}}` | Full name of the business owner |
| `profileType` | `individual` | Type of profile (Individual part) |
| `personalNumber` | `{{personalMobile}}` | Personal mobile number of the owner |
| `personalPanCard` | `{{personalPanCard}}` | PAN card number of the owner |
| `personalAbout` | `{{personalAbout}}` | Short bio about the owner |
| `profileType` | `business` | Type of profile (Business part) |
| `businessName` | `{{businessName}}` | Registered name of the business |
| `businessNumber` | `{{businessNumber}}` | Official business contact number |
| `businessRegistration` | `{{businessRegistrationNumber}}` | Udyam or other registration number |
| `gstNumber` | `{{gstNumber}}` | GST identification number |
| `businessAbout` | `{{businessAbout}}` | Detailed description of the business |
| `businessCategory[0]` | `{{businessCategory[0]}}` | First selected business category |
| `businessCategory[1]` | `{{businessCategory[1]}}` | Second selected business category |
| `businessCategory[2]` | `{{businessCategory[2]}}` | ...and so on (dynamic) |
| `address[addressLine1]` | `{{addressLine1}}` | Shop/Office number, Building name |
| `address[addressLine2]` | `{{addressLine2}}` | Street, Area, Landmark |
| `address[city]` | `{{city}}` | City name |
| `address[state]` | `{{state}}` | State name |
| `address[country]` | `{{country}}` | Country code (e.g., IN) |
| `address[pincode]` | `{{zip}}` | Postal code / PIN code |
| `address[latitude]` | `{{latitude}}` | GPS Latitude |
| `address[longitude]` | `{{longitude}}` | GPS Longitude |

---

> [!TIP]
> Ensure that all the keys listed above match exactly in your Postman **Form-Data** tab. The values wrapped in `{{ }}` will be automatically replaced with genuine data generated by the [Pre-request Script](POSTMAN_PRE_REQUEST_SCRIPT.md).
